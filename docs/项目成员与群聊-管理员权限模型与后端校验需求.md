# 项目成员 / 群聊成员 — 管理员权限模型与后端校验需求

> 前端反馈文档 · 供后端实现/校验（2026-08-20）
> 说明：此前《团队与项目-Owner管理员权限分层-后端补充需求.md》中「项目 owner」方案已废弃；
> 项目侧现在**没有 owner 概念**，统一由「项目管理员 PROJECT_ADMIN」管理。

---

## 1. 权限模型（前端已按此实现）

| 操作 | 项目管理员（PROJECT_ADMIN） | 普通成员（PROJECT_MEMBER） |
|---|---|---|
| 查看项目成员 / 群成员 | ✅ | ✅ |
| 添加成员 / 邀请入群 | ✅ | ❌ |
| 设为管理员（普通成员 → 管理员） | ✅（设置后**不可撤销**，confirm 提示） | ❌ |
| 移除普通成员 / 移出群聊普通成员 | ✅ | ❌ |
| 移除 / 降级其他管理员 | ❌（**管理员不可被操作**） | ❌ |
| 移除自己 / 管理员移除自己 | ❌ | — |

要点：
- **没有 owner**：不按项目创建者 / 群创建者判定特权，只有 `PROJECT_ADMIN`。
- **设置后不可撤销**：前端不提供「移除管理员 / 降级」入口；confirm 文案「设置后无法撤销，确定将他设置为管理员吗？」。
- **管理员不可操作其他管理员**：前端对管理员成员不显示任何操作按钮。

## 2. 前端已落地的入口

| 页面 | 入口 | 行为 |
|---|---|---|
| 项目成员页（`/app/projects/:id/members`） | 操作列 | 普通成员：设为管理员 + 移除；管理员：显示「管理员不可被操作」 |
| 群聊设置 → 成员管理（需求群） | 成员行操作 | 普通成员：设为管理员 + 移出群聊；管理员：无操作 |

## 3. 需要后端补的权限校验

### 3.1 `PATCH /projects/{projectId}/members/{userId}`（调整项目角色）

Body：`{ "role": "PROJECT_ADMIN" }`（前端只发升为管理员，不发降级）

- 仅 **PROJECT_ADMIN** 可调用（普通成员返回 403）；
- **不允许降级**：`PROJECT_ADMIN → PROJECT_MEMBER` 返回 4xx（设置后不可撤销，配合前端无降级入口）；
  - 若产品需要"转让/移除管理员"能力，需单独评审（当前冻结为不可撤销）；
- 不能把 `PROJECT_ADMIN` 成员再"升为管理员"（已生效，幂等成功即可，不要报错）。

### 3.2 `DELETE /projects/{projectId}/members/{userId}`（移除项目成员）

- 仅 **PROJECT_ADMIN** 可调用；
- **不能移除 PROJECT_ADMIN 成员** → 返回 `403 PROJECT_ADMIN_CANNOT_REMOVE_MANAGER`（或现有错误码体系中的等价码）；
- 不能移除自己（管理员把自己移出项目 → 4xx，或沿用现有最后一名管理员保护）；
- 普通成员可由管理员移除。

### 3.3 `DELETE /projects/{projectId}/groups/{groupId}/members/{userId}`（移出群聊）

- 仅 PROJECT_ADMIN 可调用（现有「创建者或 Project Admin」校验建议收紧为仅 PROJECT_ADMIN，因为不再有 owner）；
- **不能移出 PROJECT_ADMIN 成员** → 403；
- 只能移出普通成员。

### 3.4 邀请（`POST .../members` / 群成员）

- 权限维持现有：PROJECT_ADMIN 可邀请/添加入群；普通成员不可。

## 4. 错误码建议（可选）

| 场景 | 建议错误码 |
|---|---|
| 非管理员调用上述管理接口 | `403 PROJECT_ADMIN_REQUIRED` |
| 移除/移出其他管理员 | `403 PROJECT_ADMIN_CANNOT_REMOVE_MANAGER` |
| 管理员降级（PATCH 降为 MEMBER） | `409 PROJECT_ADMIN_IMMUTABLE`（不可撤销） |

## 5. 验证方式

1. 管理员 A：普通成员 B 显示「设为管理员 + 移除」；确认后 B 成为管理员，角色列变 Admin；
2. 管理员 A：管理员 B 的操作列显示「管理员不可被操作」，无移除按钮；直接调接口移除 B 返回 403；
3. 普通成员：无任何管理按钮；直接调 PATCH/DELETE 返回 403；
4. 刷新后管理员身份保持（后端持久化 role）。
